Added `attrs.trace_init()` (also available as `attr.trace_init()`): an explicit, opt-in context manager that traces instance creation of an attrs class.
It records the actual order of default factories, converters, validators, and `__attrs_post_init__` -- including `takes_self` factory visible-field identities and failure stages with attribute name and cause -- without storing field values, without rebuilding the object, and without affecting normal construction outside the `with` block.
