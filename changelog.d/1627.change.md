Added `attrs.CopyPlan` and `attrs.copy_with_plan`: explicit copy plans that copy each field according to a registered strategy (`CopyStrategy.SHARED`, `CopyStrategy.SHALLOW`, or `CopyStrategy.RECURSIVE`), with per-type policies including custom copiers and explicit rejection.
Recursive copies preserve internal sharing (two fields pointing at the same object keep pointing at one shared copy) and terminate on cyclic object graphs; `init=False` fields are carried over, frozen and slotted classes are supported, user-defined getters and `Factory` defaults are not re-run, and unsupported values raise `attrs.exceptions.UnsupportedCopyTypeError` naming the field path before anything is copied.
Run the dedicated tests with `python -m pytest tests/test_copy_plan.py -v`.
